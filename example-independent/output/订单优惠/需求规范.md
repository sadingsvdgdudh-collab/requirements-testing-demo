原始文档与不可变底稿：`input/订单优惠.md`。模块解析底稿：`output/订单优惠/解析.md`。原始 Markdown 共14行，已逐行核对，原文没有图片、表格或链接。REQ 的来源路径均相对 `output/`，用 `../input/订单优惠.md` 定位；当前保留7条要求，其中6条 active、1条 blocked、0条 deprecated。

## 1. 业务背景与范围

用户角色为已登录用户。业务范围是订单确认页金额展示、按商品金额触发的满减、取消订单回购物车及选择可用券后的提交入口。原文未说明业务目的、具体系统页面控件、订单状态名称或接口。

已确认范围可设计正式用例。失败后重试的扣券规则未确定，单独阻塞 REQ_ODC_007；不把该不确定性扩展为整个模块阻塞。金额用例使用整数元、未选择券且没有其他金额调整的测试订单；此为隔离已知满减的测试条件，不表示产品禁止其他费用或其他优惠。优惠券资格、叠加和金额精度待确认。

## 2. 功能需求

### 金额可查看

**REQ_ODC_001**

描述：已登录用户在订单确认页可以查看商品金额、优惠金额和实付金额。状态：active。

验收标准：

- AC_ODC_001_01：已登录用户打开订单确认页时，可以查看该订单的商品金额。
- AC_ODC_001_02：已登录用户打开订单确认页时，可以查看该订单的优惠金额。
- AC_ODC_001_03：已登录用户打开订单确认页时，可以查看该订单的实付金额。

来源：`../input/订单优惠.md` 第4行：“已登录用户在订单确认页查看商品金额、优惠金额和实付金额。”

### 优惠后实付展示

**REQ_ODC_004**

描述：订单确认页显示优惠后的实付金额；仅应用原文满减且没有其他金额调整的测试订单，实付金额为商品金额减去满减金额。状态：active。

验收标准：

- AC_ODC_004_01：仅应用满减且没有其他金额调整的订单，商品金额大于或等于100元时，确认页实付金额显示为商品金额减10元。
- AC_ODC_004_02：没有其他优惠或金额调整的订单，商品金额小于100元时，确认页实付金额显示为商品金额。

来源：`../input/订单优惠.md` 第7至8行，“优惠后实付金额显示在订单确认页。”数值预期由原文“减10元”和“未满100元没有满减”在隔离其它金额调整的条件下直接做减法；未补造券额、舍入或额外费用规则。

### 取消订单

**REQ_ODC_005**

描述：用户取消订单时返回购物车，不完成付款。状态：active。

验收标准：

- AC_ODC_005_01：在订单确认页取消订单后，用户返回购物车。
- AC_ODC_005_02：取消订单这条流程不会使该订单完成付款。

来源：`../input/订单优惠.md` 第11行：“用户取消订单时返回购物车，不完成付款。”

### 选择可用优惠券后可提交

**REQ_ODC_006**

描述：用户选择可用优惠券后可以点击“提交订单”。状态：active。只验证入口可点击，不将提交成功、首次扣券或支付结果作为此需求的预期。

验收标准：AC_ODC_006_01：用户在订单确认页选择一张系统标记可用的优惠券后，“提交订单”处于可点击状态并允许点击。

来源：`../input/订单优惠.md` 第14行：“用户选择可用优惠券后可以点击‘提交订单’。”原始引号见解析底稿与 JSON 来源。

## 3. 业务流程

正常流程：已登录用户到达订单确认页并查看三类金额（REQ_ODC_001）；商品金额满100元时每笔减10元且封顶10元（REQ_ODC_002），不足100元没有满减（REQ_ODC_003）；确认页展示优惠后的实付金额（REQ_ODC_004）。可用券选择后允许点击提交订单（REQ_ODC_006），原文未规定点击后的成功路径。

备选流程：用户取消订单，返回购物车且不完成付款（REQ_ODC_005）。这条流程为明示的合法选择，不补写购物车商品恢复、库存、订单终态或优惠券释放。

异常流程：原文提及提交订单失败后重试，扣券结果尚未确定（REQ_ODC_007、Q_ODC_001）；该流程保留为阻塞范围，没有正式用例。未规定非法金额、未登录、券失效、网络超时等处理，不创建其正式预期。

## 4. 输入与业务约束

金额单位为元；满减以每笔订单商品金额为条件。商品金额的允许精度、输入范围、舍入、上限及显示格式原文未规定，见 Q_ODC_004。登录是当前需求适用范围，不据此新增未登录访问限制。

### 满减阈值及封顶

**REQ_ODC_002**

描述：商品金额满100元减10元，每笔最多减10元。状态：active。封顶只用于原文满减，不能据此限制包含优惠券的总优惠金额。

验收标准：

- AC_ODC_002_01：订单商品金额大于或等于100元时，满减优惠为10元。
- AC_ODC_002_02：即使商品金额达到多个100元，单笔订单满减仍为10元，不按100元倍数累计。

来源：`../input/订单优惠.md` 第7行：“每笔订单商品金额满100元减10元，每笔最多减10元。”

### 不足阈值

**REQ_ODC_003**

描述：商品金额未满100元没有满减优惠。状态：active。

验收标准：AC_ODC_003_01：商品金额小于100元时，满减优惠金额为0元。

来源：`../input/订单优惠.md` 第8行：“商品金额未满100元时没有满减优惠。”

### 失败重试扣券安全

**REQ_ODC_007**

描述：提交订单失败后重试是否再次扣减优惠券尚未确定。状态：blocked；无已确认验收标准。Q_ODC_001 为 P0 open，只阻塞本要求，禁止自行把“不再扣券”“再次扣券”“失败返券”或幂等性作为正式预期。

来源：`../input/订单优惠.md` 第14行：“提交订单失败后重试是否再次扣减优惠券尚未确定，该规则影响扣券安全，需要先确认。”
