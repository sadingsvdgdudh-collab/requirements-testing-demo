# 新增商品需求（演示）

## 使用范围
已登录的后台用户可以打开新增商品页面，填写商品名称、商品价格，并点击“保存”或“取消”。

## 商品名称
商品名称不能为空。名称为空时，点击保存提示“请输入商品名称”，不创建商品。

## 商品价格
商品价格必须大于0，最多保留两位小数。
价格未填写、等于0、为负数或超过两位小数时，点击保存提示“请输入大于0且最多两位小数的价格”，不创建商品。

## 保存
商品名称和价格合法时，点击保存提示“保存成功”，商品列表显示本次填写的名称和价格。

## 取消
点击取消返回商品列表，不创建商品。

## 未规定的内容
重名限制、名称长度上限、价格上限、网络故障处理和并发行为未规定，需要后续确认。
