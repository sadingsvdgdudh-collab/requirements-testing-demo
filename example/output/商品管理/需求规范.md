# 商品管理需求规范

## 0. 基本信息

模块：商品管理。功能缩写：PRO。版本：1.0。
来源：input/新增商品.md（演示需求），未连接真实业务系统。
REQ清单.json为结构化数据源。本规范描述原文明确的要求。

## 1. 业务背景与范围

已登录的后台用户新增商品。页面输入商品名称、商品价格，操作为保存和取消。
范围为输入校验、正常保存及取消。原文未规定网络故障、并发、权限细分和其他商品功能。

## 2. 功能需求

- **REQ_PRO_001** 商品名称必填。AC_PRO_001_01：名称为空时提示“请输入商品名称”，不创建商品。来源第7行。
- **REQ_PRO_002** 价格必须为正数。AC_PRO_002_01：价格为0时提示价格校验错误，不创建；AC_PRO_002_02：负数时同样阻止创建；AC_PRO_002_03：正价格且其他字段合法时允许保存。来源第10–14行。
- **REQ_PRO_003** 价格最多两位小数。AC_PRO_003_01：其他字段合法时允许整数、一位小数及两位小数；AC_PRO_003_02：超过两位小数时提示价格校验错误，不创建。来源第10–14行。
- **REQ_PRO_004** 价格必填。AC_PRO_004_01：价格为空时提示价格校验错误，不创建。来源第11行。
- **REQ_PRO_005** 正常保存。AC_PRO_005_01：提示“保存成功”；AC_PRO_005_02：列表展示本次名称和价格。来源第14行。
- **REQ_PRO_006** 取消新增。AC_PRO_006_01：点击取消返回商品列表且不创建。来源第17行。

完整提示文案：价格校验错误为“请输入大于0且最多两位小数的价格”。
各条原文、来源行号、验收条件与状态见REQ清单。

## 3. 业务流程

基本流：已登录 → 打开新增页 → 输入合法名称和价格 → 保存 → 成功提示和列表展示。
备选流：打开新增页 → 填写商品 → 取消 → 返回列表且不创建。
异常流：名称为空，或价格为空/0/负数/超过两位小数 → 保存 → 相应提示且不创建。
未规定同时存在多种输入错误时的提示顺序，不设对应断言。

## 4. 输入与业务约束

名称必填。价格必填、严格大于0、最多两位小数。
当输入单位步长为0.01时，0为非法边界，0.01为最小合法正数。
未指定价格上限、名称最大长度、字符范围、去空格规则和重名规则，不自行设限制。
