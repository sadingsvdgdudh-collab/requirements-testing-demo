游戏任务奖励规则

本示例描述每日任务的领取条件、奖励和提示，供需求转录及测试设计演示。

## 领取条件

任务完成3次，可领取10金币。

| 条件 | 奖励 | 提示 |
| --- | --- | --- |
| 任务次数不足3 | 0金币 | 任务未完成 |
| 任务次数达到3 | 10金币 | 领取成功 |
| 每日限领取1次。 |  |  |
