# 名称长度测试点清单

模块代码：LEN。测试点数：4。

范围为已确认的active需求；来源从REQ清单的原文引用派生。此清单尚不代表测试点评审通过，也没有执行测试。

## TP_LEN_001 20字符合法上限允许保存

优先级：P1；场景类型：边界；设计方法：边界值。

前置条件：已打开新增商品页，其他字段合法，列表不存在本次同名商品。

检查内容：输入20个英文字母A并保存，核对商品创建。

测试数据：名称：AAAAAAAAAAAAAAAAAAAA（20个A）。

预期结果：

1. 允许保存商品。
2. 列表能找到名称为20个A的本次商品。

关联需求：REQ_LEN_001
验收标准：AC_LEN_001_01

原文来源（文件路径相对于模块的上级输出目录）：

- REQ_LEN_001 商品名称长度上限：../input/商品名称_v1.md，第5行。

> 商品名称最多允许20个字符。本例只验收由英文字母组成的名称；其他字段合法时，20个英文字母可以保存，21个或更多英文字母必须提示“商品名称最多20个字符”，且不创建商品。
