# 名称长度需求规范 v1

## 0. 基本信息

模块：名称长度，code：LEN。演示设计资料，没有执行被测软件。原文为input/商品名称_v1.md。

## 1. 业务背景与范围

验收商品名称长度和名称必填，共两条REQ。长度样例只使用英文字母，其他字符集没有定义。

## 2. 功能需求

- **REQ_LEN_001** 名称最多20个字符。AC_LEN_001_01：20个英文字母允许保存；AC_LEN_001_02：21个或更多英文字母提示“商品名称最多20个字符”且不创建。
- **REQ_LEN_002** 名称必填。AC_LEN_002_01：名称为空提示“请输入商品名称”且不创建。

## 3. 业务流程

基本流：填写合法名称和其他字段→保存→核对商品已创建。异常流：名称为空或超过上限→保存→提示且不创建。必填异常分别检查初始空值与清空已填写名称两种输入状态。

## 4. 输入与业务约束

名称上限20个字符。边界数据为20个A和21个A。其他字段合法；每条用例执行前清理同名商品，避免重名干扰。
